# Monefy-
Monefy — мобильное приложение для учёта личных доходов и расходов.

# Что это и зачем
Приложение помогает контролировать личные финансы: быстро записывать траты и поступления, видеть, на что уходят деньги, и понимать свой баланс. Всё просто и наглядно — добавил операцию в пару касаний и сразу видишь картину.

# На чём пишется
Flutter — фреймворк для кроссплатформенной разработки (Android + iOS из одной кодовой базы)

Dart — язык программирования

Visual Studio Code — среда разработки

# Что будет внутри
Добавление доходов и расходов по категориям

Круговая диаграмма расходов (как в Monefy)

История операций с фильтром по периоду (день / неделя / месяц)

Свои категории с иконками и цветами

Статистика и баланс

Тёмная тема

# Для кого
Для всех, кто хочет вести учёт личных финансов без сложных таблиц и лишних функций — быстро, просто и понятно.
